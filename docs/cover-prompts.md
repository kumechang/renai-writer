# note記事のカバー画像用プロンプト(Gemini向け)

noteの記事のカバー画像を、Geminiで作るためのプロンプト集。人物の後ろ姿のシルエットを中心にした、パステルカラーのイラストで、16:9の横長。日本語のタイトルは、画像に埋め込む。各記事のプロンプトは、コードブロックごとコピーして、そのまま貼れる。

## 使い方

1. 記事のプロンプトを、コードブロックごとコピーして、Geminiに貼る。
2. 文字が崩れたときは、「文字だけを、指定どおりに直して。背景とシルエットはそのまま」と続けて頼む。それでも直らないときは、プロンプトの「画面上部または中央に〜」から「〜はっきりさせる。」までの文字の指示を消して、背景だけ作り、Canvaなどでタイトルを入れる。
3. 日本語の長い文字は、誤字が出やすい。1行目・2行目が長いときは、2行目を省いて、1行にする方法もある。
4. 同じシリーズに見えるよう、共通ルールは変えずに、場面・背景の色・モチーフだけを、記事ごとに変えてある。

## 共通ルール(すべてのカバーに共通)

* 人物の後ろ姿・シルエットを中心に配置したパステルカラーのイラスト。表情や輪郭の細部は描き込まず、影として表現する。
* 20代後半〜30代の働く女性の後ろ姿。色あせた写真のような郷愁的な色調や、昭和・平成レトロ、少年時代を思わせるノスタルジックな意匠(セピア調、絵本的タッチ、古びた質感)は避け、現代的で洗練された生活感を保つ。
* 背景は柔らかいグラデーション+記事テーマを象徴する小さなモチーフを1つだけ添える。
* SNSのタイムラインで小さく表示されても伝わるよう、シルエットと文字のコントラストをはっきりさせる。
* 横長構図(16:9、1200×630目安)。
