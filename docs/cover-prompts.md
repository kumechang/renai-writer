# note記事のカバー画像用プロンプト(Gemini向け)

noteの記事のカバー画像を、Geminiで作るためのプロンプト集。16:9の横長で、日本語のタイトルを画像に埋め込む前提。各記事のプロンプトは、そのままコピーして貼れるように、共通のスタイルと、文字の指定を含めてある。

## 使い方

1. 記事の見出しのプロンプトを、コードブロックごとコピーして、Geminiに貼る。
2. 文字が崩れたときは、「文字だけを、指定どおりに直して。背景はそのまま」と続けて頼む。それでも直らないときは、下の「文字なし版」で背景だけ作り、Canvaなどでタイトルを入れる。
3. 日本語の長い文字は、誤字が出やすい。メインタイトルを短くしたいときは、サブタイトルを省く。
4. 同じシリーズに見えるよう、共通のスタイルを変えずに、場面だけを変える作りにしてある。

```

画像内の文字は、下に指定した日本語だけにする。一字も変えず、誤字・脱字・余計な文字・ロゴ・透かし・署名は入れない。書体は、太めで読みやすいゴシック体。メインタイトルは大きく、サブタイトルは小さく、白か濃紺で、背景とのコントラストをはっきりさせる。
```

## 文字なし版にするとき

各プロンプトの「文字:」の部分(メインタイトルとサブタイトル)を、次の一文に置き換える。

```
画像内に、文字は一切入れない。タイトル用に、画面の右側か下側に、落ち着いた色の広い余白を残す。
```
