# SNSアカウント立ち上げ〜成長のプレイブック(汎用版)

新しいジャンルのXアカウントを立ち上げて、フォロワーを増やし、(必要なら)note などの商品に
つなげるまでの手順をまとめたものです。恋愛ジャンルのアカウントを約1か月運用して、診断と
改善を繰り返した過程から、ジャンルに依存しない部分を取り出しています。

## このドキュメントの読み方

- **根拠の強さに注意してください。** 元になっているのは、1アカウント・約1か月・バズった返信1件
  という少ない経験です。各ルールには、根拠の強さのタグを付けています。
  - `【観測】`: このアカウントの数字で確かめられたこと(ただし1アカウントの範囲)
  - `【仮説】`: 筋は通っているが、まだ数字で確かめていないこと
  - `【一般論】`: SNS運用で広く言われていること(このアカウントでは未検証)
- **`〈恋愛の例〉`** は、実際にあったことです。ジャンルが違えば、中身は置き換えてください。
- 新しいアカウントで試して、タグを更新していくのが前提です。

## 全体の流れ

| フェーズ | 目的 | 主な成果物 | 次へ進む条件 |
|---|---|---|---|
| 0 | ゴールとターゲットを決める | 戦略シート | ターゲットと約束を1文で言える |
| 1 | 市場と手本を調べる | 近いアカウントの調査、型の候補 | 当たっている型を3つ以上挙げられる |
| 2 | 受け皿を作る | プロフィール、固定投稿、導線 | 初見の人に「誰向けか・何が読めるか」が伝わる |
| 3 | 初期運用(2週間) | 返信と投稿、日次の記録 | 記録が残っている |
| 4 | 診断する | 診断メモ | 詰まっている段階を特定できた |
| 5 | 専門家の目で見直す | 修正案(優先順位付き) | 修正が反映された |
| 6 | 型を抽出して反映する | 型のライブラリ、プロンプト | コピーでなく型として反映できた |
| 7 | 計測と週次レビュー | レポート、実験 | 週次のループが回っている |
| 8 | 見直し(月次・四半期) | 戦略シートの更新 | 判断の根拠が数字で残っている |

## フェーズ0: ゴールとターゲットを決める

**目的**: 何のためにやるのか、誰に向けるのかを、最初に決める。

### やること

1. **ゴールを数字と期限で決める**
   - 例: 「3か月でフォロワー◯人」「noteの月売上◯円」「認知だけ」
   - フォロワー数を目的にするか、商品の売上を目的にするかで、必要な投稿の種類が変わる。
     両方なら、優先順位を決める
2. **ターゲットを具体的に描く**
   - 年代・性別・状況・悩み・Xを見る場面・探している情報・使う言葉
   - **「あえて外す人」も書く**(全員に向けると、誰にも刺さらない)
   - 【仮説】ペルソナは3人ほど。「保存する人」「情報収集型」「感情が揺れている人」のように、
     保存する理由が違う人を混ぜると、レビューに使いやすい
3. **約束(ポジショニング)を1文で書く**
   - 「誰が、誰に、何を約束するか」
   - 〈恋愛の例〉「意志が弱いからではない。心のしくみで執着をゆるめる」
4. **発信の柱とテーマの比率を決める**(まず中心の柱を1つ、周辺は全体の1割程度から)
5. **書き手の立場と、守る線を決める**
   - 実在の書き手の体験を使うのか、考え方に絞るのか。**AIが生成する部分は、体験談を使わず、場面の
     描写・観察・考え方で書く**のを基本にする(〈恋愛の例〉「私もそうだった」「私は〜してた」のような
     体験談を、設定・返信ガイド・安全チェックから外した)
   - 実在しない体験談や取材を、事実のように書かない(「〜な人の多くが」「〜できた人は」)
6. **ジャンル固有の安全ルールを決める**(§付録Cのチェックリスト)

### 成果物

**戦略シート**(§付録Aのテンプレート)。以降のすべてのプロンプト、レビュー、プロフィールは、
ここから導く。同じ内容を複数のファイルに別々に書かない(片方を直すと、もう片方が古くなる)。

## フェーズ1: 市場と手本を調べる

**目的**: 同じ読者に向けて、すでに何が当たっているかを知る。

### やること

1. 近いジャンルのアカウントを10〜20件集める(フォロワーが多い順でなく、**自分のターゲットが反応して
   いる順**に)
2. 伸びている投稿を各アカウント数件ずつ読み、**型**に分解する(§付録B)
   - 書き出し、場面、締め、長さ、保存・返信される理由
3. 自分が出さない領域(競合と被る、安全上避ける)を決める
4. ターゲットが実際に使っている**言葉**(悩みの言い方)を集める。検索や、返信先の投稿から拾う

### 成果物

- 手本の投稿と、その型の候補(3つ以上)
- 差別化の案(近いアカウントとの違い)

## フェーズ2: 受け皿を作る

**目的**: 返信や投稿から来た人が、フォローしたくなる状態にしておく。**先にやる**(来た人を逃さないため)。

### プロフィール `【一般論】`

- **誰向けか**、**何が読めるか**、**書き手は誰か**を入れる
- 長い説明、講義のような言葉、読者にラベルを貼る言葉は避ける
- 普段の口調と、プロフィールの口調をそろえる
- 文字数の上限(160字)に収める

### 固定投稿 `【観測】`

- **売り込みにしない。** 初めて来た人が最初に見るのが、値引き付きの宣伝だと、フォローの理由にならない
- 初見の人に、価値が1投稿で伝わるもの(チェックリスト、保存したくなる基準など)にする
- 〈恋愛の例〉以前は有料記事の宣伝(「リポストでお得に読める」)だった → チェックリスト型の投稿に変更

### 導線

- 流れを決めておく: 返信・投稿 → プロフィール → フォロー → **無料の入口コンテンツ** → 有料商品
- リンクは、**売る記事ではなく、無料の入口**に向ける
- 各段に指標を置く(§フェーズ7)

### 成果物

プロフィール、固定投稿、無料の入口コンテンツ(あれば)。

## フェーズ3: 初期運用(2週間)

**目的**: 反応のデータを集める。まだ完成度を求めない。

### 運用の中心は返信 `【観測】`

〈恋愛の例〉直近4週間で、返信は表示数の約98.5%を占めた。自分の投稿(261件)は合計約9,600表示、
フォローはほぼゼロだった。立ち上げ期は、**自分の投稿を量産するより、返信に時間を使う**ほうが、
届く範囲が広い。

ただし、返信の表示数は一部の当たりに偏る(上位3件で85%)。外れが多いのが普通で、
1件ごとに一喜一憂しない。

### 返信する投稿の選び方 `【仮説】`

- 表示数がそこそこあり、**まだコメントが少ない**もの(伸びている最中に早く入る)
- ターゲットの悩みに近いもの(**プロフィールの約束とつながる話題**を優先する)
- 避けるもの: 画像・リンク先に依存して中身が分からない投稿、安全上触れない話題、
  性別・属性で二分して争っている投稿
- 〈恋愛の例〉自動の候補検索(キーワード検索)は、数週間候補ゼロのまま動いていて、誰も気づかなかった。
  人が自分で見て選ぶほうが、実際に当たりが多かった。**自動化した仕組みは、出力件数を監視する**

### 記録するもの(必ず最初から)

返信ごとに、後で分析できる情報を残す。

- 日時、親投稿のURL・本文
- **返信した時点の、親投稿の表示数・コメント数・経過時間**(あとから取れない)
- テーマ(柱のどれか)、使った型
- 返信文
- 結果(表示、いいね、ブックマーク、プロフィールアクセス)

加えて、**フォロワー数を毎日記録する。** `【観測】` アナリティクスの投稿別「新しいフォロー」は、
実際より大きく少なく出る(〈恋愛の例〉4週間で3件、実際のフォロワーは38人)。投稿別のフォロー数は
信用せず、日次のフォロワー数を正とする。

### 成果物

返信ログ、日次のフォロワー数、週次のアナリティクスのCSV。

## フェーズ4: 診断する

**目的**: 「どの段階で人が落ちているか」を特定する。

### 診断の順番

次の順に見て、**最初に詰まっている段階**を直す。後ろの段階を直しても、前が詰まっていれば効かない。

| 段階 | 見る数字 | 詰まっているときの例 |
|---|---|---|
| ① 届いているか | 表示数、1件あたりの中央値 | 表示が桁違いに少ない(数十) |
| ② 反応されているか | いいね率、ブックマーク率、返信率 | 表示はあるが、いいねもブックマークもない |
| ③ プロフィールを見に来るか | プロフィールアクセス ÷ 表示数 | 反応はあるが、プロフィールに来ない |
| ④ フォローされるか | フォロワー増 ÷ プロフィールアクセス | プロフィールには来るが、増えない |
| ⑤ 導線が動くか | URLクリック、無料コンテンツの閲覧、購入 | フォローはあるが、商品につながらない |

### 診断で見る具体的な点 `【観測】`

- **投稿の中身が、その投稿だけで完結しているか。** 続きを読ませる形(途中で切る、答えを2件目に伏せる)は、
  1件目が読まれない環境では、いいねも保存もされない
- **書き出し・締めが固定化していないか。** 同じ型が続くと、タイムラインで読み飛ばされる
- **投稿の本数が多すぎないか。** 〈恋愛の例〉1日8件だったが、3件に減らしても(実際の投稿は1日1〜6件)、
  成果は変わらなかった。本数は、成果に効いていなかった
- **ブックマークがあるか。** 〈恋愛の例〉診断時点で0件。保存される理由(持ち帰れる中身)が無かった
- **リンクが漏れていないか。** 〈恋愛の例〉生成ツールの共有リンクが、投稿に混ざっていた。自動投稿は、公開前の
  チェックが必要
- **配信の問題を疑う前に、規制の有無を確認する。** 〈恋愛の例〉シャドウバンではなかった

### 成果物

診断メモ(どの段階が詰まっているか、根拠の数字)。

## フェーズ5: 専門家の目で見直す

**目的**: 自分の視点だけでは気づけない問題を、複数の目で洗い出す。

### 専門家パネルの作り方

Claude に、次のような役を順に(または並行して)担当させる。**役ごとに見る観点を分け、同じ指摘が
重なったものを優先**する。

| 役 | 見る観点 |
|---|---|
| SNS運用のインフルエンサー | 反応・拡散・フォローにつながるか。型の固定化、1行目の強さ |
| ターゲットのペルソナ(複数) | 保存するか、しないか。保存する理由、しない理由 |
| 臨床心理士(ジャンルが人の心に触れる場合) | 読者を傷つけないか。判定・ラベル・断定、危険な話題 |
| Xの成長の実践者 | 投稿の構造、返信戦略、プロフィール |
| 商品の販売の実践者(商品がある場合) | 導線、価格、無料と有料の分け方、タイトル |
| 編集者・コピーライター | 文章の質、タイトル、読みやすさ |

### 進め方

1. 各専門家に、**現状のデータ(数字と実際の投稿)を渡して**、問題と修正案を出させる
2. 修正案を集めて、**優先順位を付ける**(効果が大きく、小さな変更で済むものから)
3. **安全面の指摘は、優先順位に関係なく、先に反映する**
4. 反映したあとの出力を、ペルソナに見せて、保存・購入の判断を確かめる(ブラインドテスト。新旧を
   ラベルなしで見せて、どちらを選ぶか)

### 〈恋愛の例〉実際に反映した修正

- 保存される投稿の型を追加し、保存判定をレビューに組み込んだ(保存するペルソナが0人なら、保存型は不合格)
- 1件目だけで完結する形にした。書き出し・締めの固定化を禁止した。アカウント全体の直近の書き出しを
  生成時に見せて、重複を避けた
- 投稿本数を減らした(8件 → 3件)
- **安全ゲート**を追加した。安全違反が1つでもあれば、自動投稿でも手動承認に回す
- 記事のURLは、**許可リスト(自分の公開記事のURLパターン)に合うものだけ**を投稿に使う。リンク付き投稿の
  週あたりの上限を決めた
- 売れていない有料記事7本を、専門家レビュー → ライターが書き直し → ペルソナの購入テスト → 編集長の最終
  レビューの順で見直した。**実在しない体験談・取材のように見える記述は、すべて直した**

### 成果物

優先順位付きの修正リストと、反映後の設定・プロンプト。

## フェーズ6: 当たった型を抽出して、反映する

**目的**: たまたま当たった投稿から、**再現できる型**だけを取り出す。

### 手順

1. 当たった投稿を、**型の動き**に分解する(§付録B)
2. 当たった理由を**仮説として**書く。「配信のされ方(親投稿が大きかった)」と「文章の力」を分けて考える
   - 〈恋愛の例〉42.5万回表示の返信は、数字の大半が親投稿の大きさによる。単独の投稿では、同じ数字は出ない
3. **型だけを反映し、文面や話題をコピーしない。** 手本の文言をそのまま借りると、同じアカウントの投稿が
   テンプレに見える
4. **文型・書き出し・語尾は、毎回変える。** 型(動き)は守り、文の形は変える
5. 反映したあと、**1件の当たりに合わせすぎていないか**を確かめる。〈恋愛の例〉当たった話題(結婚相手の条件)に
   テーマを広げたが、来た人はプロフィールの中心テーマの読者とは別の層だった可能性が高く、比率を3割から1割に
   戻した(【仮説】。フォロワーの日次推移で確かめる)

### 返信の型 `【仮説】`

1. **相手の言葉を拾う**(短い言い回しを「」で引用)
2. **日常の具体的な場面で、良さを描く**(五感に近い一文)
3. **誰も悪く言わない基準で閉じる**(「〜は人それぞれでも、〜な人が一番」)

さらに、プロフィールまで来てもらうために:

- **保存したくなる一行を1つ作る**(親投稿の言葉を一段ずらす、区別を言い切る)
- **丸く収めるだけで終わらない**(新しい視点を1つ足す。ただし誰も悪く言わない)
- **感想や褒め言葉で終わらせない。** 〈恋愛の例〉いいね率の低い返信は、感想で終わっていた

### 成果物

型のライブラリ、プロンプトへの反映、**返信ガイド**(Claude に渡す、単体で完結したmd)。

## フェーズ7: 計測と週次レビュー

**目的**: 数字を見て、次の1週間の実験を決める。

### 見る指標

| 指標 | 見方 |
|---|---|
| フォロワーの純増(日次) | 正とする指標。週単位で見る |
| プロフィールアクセス ÷ 表示数 | ③の段階。話題とプロフィールの一致を測る |
| フォロワー増 ÷ プロフィールアクセス | ④の段階。プロフィールの出来を測る |
| 返信の当たり率(表示1,000以上の割合) | 返信する投稿の選び方を測る |
| いいね率、ブックマーク率 | ②の段階。型の出来を測る |
| テーマ別のフォロワー増 | 柱の比率を決める材料 |
| URLクリック、購入 | ⑤の段階 |

### 週次レビューの手順(1回15分)

1. アナリティクスのCSVとフォロワー数を入れる
2. Claude がレポートを作る(増減、上位・下位の返信の分析、テーマ別、転換率、前週の仮説の判定)
3. **提案は最大3つ**(設定の変更、次週の実験)
4. 承認した分だけ、設定ファイルの変更として反映する(変更履歴を残す)

### 実験の書き方

「◯◯をすると、△△が増える(減る)」+「見る指標」+「期間」+「判定基準」を、事前に書く。後から
理由をつけて判定しない。

### 〈恋愛の例〉実験にできるテーマ

- 「関係の条件の返信」と「失恋・未練の返信」で、フォロワー増が違うか(テーマを返信ログに付けて集計)
- プロフィール変更(固定投稿・プロフィール文)の前後で、転換率が変わるか

### 成果物

週次レポート、実験の記録、設定の変更履歴。

## フェーズ8: 見直し(月次・四半期)

| 周期 | 見直すこと | 判断の材料 |
|---|---|---|
| 週次 | 戦術: 型、話題の比率、返信の選び方 | 週次レポート |
| 月次 | ターゲットと約束: 実際のフォロワーが想定と合っているか | 直近のフォロワー20人のプロフィール、ブックマークした人 |
| 四半期 | ゴールと導線: 何を目指すか、商品の売り方 | フォロワー推移、購入、導線の各段の数字 |

### 続ける/見直す/やめる基準

アカウントを始める前に、基準を決めておく。例:

- 4週間でフォロワーが目標の半分に届かない → ターゲットと約束を見直す
- 2か月で、プロフィールアクセスからの転換が下がり続ける → 受け皿(プロフィール・固定投稿)を作り直す
- 3か月で、目標の3割に届かない → ジャンルや切り口を見直すか、やめる

## 付録A: 戦略シートのテンプレート

```markdown

版: v1 / 更新日: / 更新理由:

## 1. ゴール
- 目的: (フォロワー / 商品の売上 / 認知)
- 数字と期限:
- 優先順位:

## 2. ターゲット
- 主なターゲット: (年代・性別・状況)
- 悩み・探している情報:
- Xを見る場面:
- 使う言葉:
- あえて外す人:
- ペルソナ(3人ほど): 名前 / 状況 / 保存する投稿 / 保存しない投稿

## 3. 約束(ポジショニング)
- 1文:
- 近いアカウントとの違い:
- プロフィール文(160字以内):
- 固定投稿:

## 4. 発信の柱
- 中心の柱: 
- 周辺の柱(比率の上限): 
- 使う型: (保存型の種類、返信の型)
```

## 付録C: ジャンル別の安全チェックリスト

自動投稿や返信案の生成には、**安全ゲート**(違反が1つでもあれば、手動承認に回す)を入れる。
共通のルールと、ジャンル固有のルールを分けて書く。

### 共通

- 実在しない体験談・取材・統計を、事実のように書かない(書き手・友人・知人の体験談も作らない)
- 出典のない数値を書かない
- 「絶対に」「100%」「必ず」など、根拠のない断定を使わない
- 読者の状態を判定しない(「〜な時点でまだ終わっていない」)
- 読者や第三者(性別・属性・職業の人)に、否定的なラベルを貼らない
- 回復や成果の期限を示さない
- 宣伝・フォロー依頼・リンクを、返信に入れない。生成ツールの共有リンクが混ざっていないか確認する
- 政治・宗教・差別・性的な話題・炎上目的の話題を扱わない

### ジャンル固有(例)

| ジャンル | 追加で避けること |
|---|---|
| 恋愛 | 希死念慮・自傷・DV・モラハラ・性暴力・精神疾患。拒否された後の接触・相手の居場所を探る行動の肯定。心理学・脳の話の断定 |
| 健康 | 診断・治療の断定。薬・サプリの効果の断言。専門家への相談を妨げる表現 |
| お金・投資 | 利益の保証。特定の銘柄・商品の推奨。リスクの隠蔽 |
| 法律・税 | 個別の事案への断定的な判断。専門家への相談を妨げる表現 |
| 育児・教育 | 他の家庭のやり方の否定。医療・発達に関する断定 |

(上の表は一般的な例です。ジャンルの規約・法令・プラットフォームのルールは、実際に確認してください。)

## 付録D: 実際にやって、うまくいかなかったこと(失敗の記録)

次の運用で同じことをしないための記録です。

1. **自動化した候補検索が、数週間、候補ゼロのまま動いていた。** 出力件数を監視しておらず、誰も気づかなかった
2. **投稿別の「新しいフォロー」を、そのまま信じかけた。** 実際より大きく少なく出る。日次のフォロワー数を正にする
3. **当たった1件に合わせて、テーマを広げすぎた。** 1件のデータで戦略を変えず、テーマ別の結果を集めてから決める
4. **手本の文言が、他の返信にそのまま移った。** 型だけを渡し、文面は渡さない。文型も毎回変える
5. **固定投稿が売り込みだった。** 初見の人には、価値が伝わる投稿を最初に見せる
6. **本数を増やせば伸びると考えていた。** 本数は成果に効かなかった。返信とプロフィールに時間を使う
7. **私(Claude)が、返信案の点数を「予測」のように扱った。** 点数は読みであって、予測ではない。数字で確かめる
8. **生成ツールの共有リンクが、投稿に混ざった。** 自動投稿には、公開前のチェックを入れる
