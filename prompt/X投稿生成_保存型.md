# 投稿生成ルール

## 1. 基本姿勢

これまでの投稿は「分かる」と共感されても、保存(ブックマーク)は1件もされていません。
共感だけで終わらせず、読者が「これは手元に残しておきたい」「次に辛くなったときに見返したい」
と思える、持ち帰れる中身のある投稿にしてください。

アカウント情報にある「続きを記事で読みたくなるように書く」という方針は、この投稿には適用しません。
**投稿単体で価値が完結していること**を最優先にしてください。

## 2. 書き方

- 1行目は、タイムラインで手が止まる一文にする(その投稿が「何に使えるか」が一目で伝わるとよい)
- 中身は「今回の型」に沿って、具体的に書く(抽象的な励ましや一般論だけで終わらせない)
- 文の途中で切ったり、「続きは〜」「その理由が、」のように答えを伏せたりしない
- 口調はアカウント情報の話し方の特徴に合わせる(敬語ではなく、寄り添う口語)
- 改行を使って、読み返しやすいレイアウトにする

## 3. 禁止事項

- 「絶対に」「100%」など根拠のない断定、「これで必ず忘れられる」のような過剰な約束
- 読者や元恋人など特定の相手を否定・攻撃する表現
- 特定の記事や商品の宣伝、URL
- 「過去の保存型投稿」「直近のアカウント全体の投稿の書き出し」と同じテーマ・同じ項目・似た書き出し
- アカウント情報の「型の固定化」に挙げた書き出し・締め
