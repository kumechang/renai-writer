# 投稿生成ルール

## 1. 基本姿勢

記事の宣伝広告ではなく、この記事を読んで考えたことをXで自然に共有する投稿を書いてください。

このアカウントは今、記事へのクリックよりも、投稿単体のインプレッション・エンゲージメントを
優先しています。記事を読んでいない人が読んでも、それ単体で「分かる」「刺さった」と
思える投稿にしてください。

読者が、

「分かる」
「言われてみればそうかも」
「これは手元に残しておきたい」
「この人の考え、もっと読みたい」

と思える文章を優先してください。

## 2. 冒頭

最初の1文を最も重要な部分として扱ってください。記事の見出しをそのまま繰り返すのではなく、
記事の中の具体的な一場面や、読者がハッとする一文を冒頭に置いてください。
問いかけ(「〜ない?」「〜してたりしない?」)で書き出さないでください。

## 3. 構成

以下の順番を基本としてください。

具体的な場面・共感(冒頭)
↓
それについての気づき・答え・自分の考え(記事の中の一つに絞り、投稿の中で言い切る)
↓
{{article_url_section_note}}

## 4. 禁止事項

- 記事の見出しや結論をそのまま並べただけの要約
- 「絶対に」「100%」など根拠のない断定
- 読者や元恋人など特定の相手を否定・攻撃する表現
- 過剰な煽り(「これを読めば解決」など)
- 「この記事からの過去の投稿」「直近のアカウント全体の投稿の書き出し」と同じ切り口・同じネタ・似た書き出し
- アカウント情報の「型の固定化」に挙げた書き出し・締め・切り方
  (この記事に複数の見出し・ステップがある場合、過去の投稿で使っていない別の部分に
  焦点を当ててください)
- 「公開状況」が未公開の場合、内容の具体的な詳細・結論・引用を明かすこと
  (テーマや興味を引く一言に留め、あくまで「匂わせ」にしてください)
- 「直近のトレンドワード」を無理やり詰め込むこと(記事の内容と関係ないのに
  ハッシュタグを付け足すなど。自然に絡められそうな場合だけ触れてください)
