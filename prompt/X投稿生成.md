# 投稿生成ルール

## 1. 基本姿勢

記事の宣伝広告ではなく、この記事を読んで考えたことをXで自然に共有する投稿を書いてください。

読者が、

「分かる」
「それ気になる」
「自分はこうかも」
「続きが読みたい」

と思える文章を優先してください。

## 2. 冒頭

最初の1文を最も重要な部分として扱ってください。記事の見出しをそのまま繰り返すのではなく、
記事の中で一番刺さる気づき・問いかけ・共感できる一文を冒頭に置いてください。

## 3. 構成

以下の順番を基本としてください。

気づき・共感(冒頭)
↓
記事で扱っている内容の一端(要約ではなく、続きが気になる程度の情報量)
↓
{{article_url_section_note}}

## 4. 禁止事項

- 記事の見出しや結論をそのまま並べただけの要約
- 「絶対に」「100%」など根拠のない断定
- 読者や元恋人など特定の相手を否定・攻撃する表現
- 過剰な煽り(「これを読めば解決」など)
