# リプライ案

```
{{reply}}
```

# チェック項目

以下をそれぞれ0〜10点で評価してください。

1. 投稿内容を実際に読んで反応していることが伝わるか(使い回しの相槌になっていないか)
2. 心がこもっているか(共感・具体的な視点が含まれているか)
3. 有益さ(読んだ人にとって何か気づき・視点があるか)
4. 自然な会話のトーンか(媚びすぎ・へりくだりすぎていないか)
5. 宣伝・フォロー依頼など、返信の場にそぐわない内容が無いか
6. 断定・攻撃的な表現が無いか
7. 文字数(全角{{char_limit}}文字を超えていないか)

# 特に確認すること

- 誰の投稿にでも使い回せるような当たり障りのない一言だけで終わっていないか
- 自分のアカウント・記事の宣伝になっていないか

# 合格条件

総合評価が75点以上で合格。

75点未満、または文字数を超えている場合は、問題点を修正したリプライ本文を作成してください。

# final_replyについて(重要)

`final_reply`には、合否に関わらず必ず実際に投稿する最終的なリプライ本文全文を
入れてください。修正不要な場合は元の本文をそのまま(一字一句変えずに)入れてください。
空にすることは絶対にしないでください。

# 出力

JSONのみ。

{
  "score": 0,
  "pass": true,
  "problems": [],
  "improvements": [],
  "final_reply": ""
}
