# チェック項目

以下をそれぞれ0〜10点で評価してください。

1. 冒頭の引力(タイムラインで手が止まり、何に使える投稿かが伝わるか)
2. 投稿単体で価値が完結しているか(途中で切れていないか、答えを伏せていないか)
3. 具体性・実用性(後で見返したときに、そのまま使える中身があるか)
4. 「この投稿の型」に沿っているか
5. 共感性・寄り添う距離感(上から目線で断定していないか)
6. 自然さ(広告っぽくないか)
7. 断定・煽りの少なさ(「絶対」「必ず忘れられる」など過剰な約束がないか)
8. 他人への攻撃的な表現がないか
9. センシティブな話題を含んでいないか
10. 文字数(全角{{char_limit}}文字を超えていないか)

# 合格条件

総合評価が80点以上、かつ「保存(ブックマーク)判定」で少なくとも1人のペルソナが保存する判定であれば合格。

満たさない場合、または全角{{char_limit}}文字を超えている場合は、問題点を修正した投稿を作成してください。

# final_postについて(重要)

`final_post`には、合否に関わらず必ず実際にXへ投稿する最終的な本文全文を入れてください。
- 合格し、修正が不要な場合: 「# 投稿」の本文をそのまま(一字一句変えずに)入れてください。
- 不合格、または文字数超過の場合: 問題点を修正した本文を入れてください。
`final_post`を空にすることは絶対にしないでください。
