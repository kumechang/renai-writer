# チェック項目

以下をそれぞれ0〜10点で評価してください。

1. 冒頭の引力
2. 共感性
3. 自然さ(広告っぽくないか)
4. 会話性(返信・引用したくなるか)
5. 記事本文との整合性(記事に書かれていないことを主張していないか)
6. 投稿単体での完結度(気づき・答えまで言い切っているか。見出しを並べただけの要約になっていないか)
7. 断定・煽りの少なさ
8. 他人への攻撃的な表現がないか
9. センシティブな話題を含んでいないか
10. 文字数(全角{{char_limit}}文字を超えていないか)

# 特に確認すること

- 見出しや結論をそのまま並べただけの要約になっていないか
- 文の途中で切ったり、答えを伏せたまま終わったりしていないか
- 書き出しが「〜ない?」「〜してたりしない?」のような問いかけになっていないか、
  締めが「自分を責めなくていい」「もう大丈夫」のような定型の励ましになっていないか
- リンクが無いのに「記事を書いた」「記事にまとめた」と記事の存在だけを伝えていないか
  (まだ公開前の記事を匂わせる投稿の場合を除く)
- 「絶対に」「100%」など根拠のない断定をしていないか
- 元恋人や特定の相手を否定・攻撃する表現がないか
- 全角{{char_limit}}文字を超えていないか

# final_postについて(重要)

`final_post`には、合否に関わらず必ず実際にXへ投稿する最終的な本文全文を入れてください。
- 合格し、修正が不要な場合: 「# 投稿」の本文をそのまま(一字一句変えずに)入れてください。
- 不合格、または文字数超過の場合: 問題点を修正した本文を入れてください。
`final_post`を空にすることは絶対にしないでください。
