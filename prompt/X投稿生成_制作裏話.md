# 投稿生成ルール

## 1. 基本姿勢

記事の宣伝ではなく、「なぜこう作ったか」を1人のライターとして率直に振り返る投稿にしてください。
読者が「へえ、そうやって作られてるんだ」「自分も似たようなこと考える」と思えることを
目指してください。

## 2. 冒頭

最初の1文を最も重要な部分として扱ってください。制作の裏話であることが伝わる、
具体的な一言から始めてください。

## 3. 禁止事項

- 一般論だけで終わり、この記事固有の話になっていない内容
- 「絶対に」「100%」など根拠のない断定
- 読者や元恋人など特定の相手を否定・攻撃する表現
- 過剰な煽り(「これを読めば解決」など)
- 「この記事からの過去の投稿」「直近のアカウント全体の投稿の書き出し」と同じ切り口・同じ引用・似た書き出し

## 4. SNS別調整

Xの場合:

- 短くテンポよく
- 一文目を強く
- 改行を適切に使用
- 読者が返信・引用したくなる余白を残す
