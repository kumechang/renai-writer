# チェック項目

以下をそれぞれ0〜10点で評価してください。

1. 1件目の引力(タイムラインで手が止まるか)
2. 1件目だけで完結しているか(気づき・答えまで言い切っていて、文の途中で切ったり
   答えを2件目に伏せたりしていないか)
3. 2件目が1件目の繰り返しではなく、記事にある具体的な方法・理由を足しているか
4. 記事本文との整合性(記事に書かれていないことを主張していないか)
5. 自然さ(広告っぽくないか)
6. 断定・煽りの少なさ
7. 他人への攻撃的な表現がないか
8. センシティブな話題を含んでいないか
9. 1件目の文字数(全角{{char_limit}}文字を超えていないか)
10. 2件目の文字数(全角{{char_limit}}文字を超えていないか。記事URL分の余白も考慮する)

# 特に確認すること

- 1件目が答えを伏せたまま、文の途中で切れていないか
- 記事全体の要約や見出しの羅列になっていないか
- 書き出しが「〜ない?」「〜してたりしない?」のような問いかけになっていないか、
  締めが「自分を責めなくていい」「もう大丈夫」のような定型の励ましになっていないか
- 2件目の本文にURLやリンクへの言及が含まれていないか(自動付与されるため不要)
- 「絶対に」「100%」など根拠のない断定をしていないか
- 元恋人や特定の相手を否定・攻撃する表現がないか

# 合格条件

総合評価が80点以上で合格。

80点未満、または文字数を超えている場合は、問題点を修正した本文を作成してください。

# final_hook / final_payoffについて(重要)

`final_hook`・`final_payoff`には、合否に関わらず必ず実際に投稿する最終的な本文全文を
入れてください。修正不要な場合は元の本文をそのまま(一字一句変えずに)入れてください。
どちらも空にすることは絶対にしないでください。
