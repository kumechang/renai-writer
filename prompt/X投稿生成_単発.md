# 投稿生成ルール

## 1. 基本姿勢

宣伝や告知ではなく、読者が自分の状況と重ねて読める気づき・あるある・問いかけを書いてください。

読者が、

「分かる」
「言われてみればそうかも」
「これは手元に残しておきたい」
「この人の考え、もっと読みたい」

と思える文章を優先してください。

## 2. 1件目(本題)の書き方

- 最初の1文を最も重要な部分として扱ってください。日常の具体的な一場面や、よく言われる通説など、
  読者が「自分のことだ」「本当にそう?」と手を止める一文から始めてください。
  問いかけ(「〜ない?」「〜してたりしない?」)で書き出さないでください。
- 以下のいずれかを目安にしてください(毎回同じ方向性にならないよう変化をつける)。
  - 恋愛の執着・未練にまつわる具体的な場面と、その正体についての気づき
  - よく言われる通説への、自分なりの異論
  - 気づかないうちにハマっている行動パターンと、その抜け方
- 気づき・答え・自分の考えまで、1件目の中で言い切ってください。
  「その理由は、」「それって多分——」のように文の途中で切ったり、答えを2件目に伏せたりしないでください。

## 3. 2件目(補足)の書き方

- 1件目を読んで興味を持った人に向けて、具体例・もう一歩深い話・今日からできる小さなコツなど、
  1件目とは別の価値を足してください(1件目の言い換えや繰り返しにしない)。
- 断定的な「正解」ではなく、読者が納得したり、少し楽になったりする視点を提示してください。
- 締めは言い切り、または答えやすい問いかけにしてください。
  「自分を責めなくていい」「もう大丈夫」のような定型の励ましで締めないでください。

## 4. 禁止事項

- 「絶対に」「100%」など根拠のない断定
- 読者や元恋人など特定の相手を否定・攻撃する表現
- 過剰な煽り
- 特定の記事や商品の宣伝(今回は記事に紐づかない投稿のため)
- 「過去の単発投稿」「直近のアカウント全体の投稿の書き出し」と同じテーマ・同じネタ・似た書き出し
- アカウント情報の「型の固定化」に挙げた書き出し・締め・切り方
- 「直近のトレンドワード」を無理やり詰め込むこと(自然に絡められそうな場合だけ触れてください)
