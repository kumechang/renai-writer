# 投稿生成ルール

## 1. 基本姿勢

宣伝や告知ではなく、読者が自分の状況と重ねて読める気づき・あるある・問いかけを書いてください。

読者が、

「分かる」
「それ気になる」
「自分はこうかも」
「これ聞いてほしい」

と思える文章を優先してください。

## 2. 1件目(問題提起)の書き方

- 最初の1文を最も重要な部分として扱ってください。日常の一場面・感情の動き・あるあるなど、
  読者が自分ごととして不安になったり、ドキッとしたりする問題提起から始めてください。
- 以下のいずれかを目安にしてください(毎回同じ方向性にならないよう変化をつける)。
  - 恋愛の執着・未練にまつわる「あるある」
  - 気づかないうちにハマっている行動パターンへの警鐘
  - 読者が思わず自分と重ねてしまう問いかけ
- 文の途中、話が完結する手前で切ってください。「そんなとき、」「では」「実は」「そう思っていたら」
  など、続きが気になる接続語・言い回しで終えてください(体言止めや単なる問いかけで終わらせる
  のではなく、あくまで「文が完結していない」状態で切ることが重要です)。
- 1件目で答え・解決策・結論までは書かないでください(2件目に譲ってください)。

## 3. 2件目(回答)の書き方

- 1件目の続きから自然につながる書き出しにしてください(1件目を読み返さなくても意味が
  通るように、話の要点は簡潔に繰り返して構いません)。
- 1件目で提起した問題への気づき・考え方の転換・短い持論など、答えにあたる内容を書いてください。
- 断定的な「正解」ではなく、読者が納得したり、少し楽になったりする視点を提示してください。

## 4. 禁止事項

- 「絶対に」「100%」など根拠のない断定
- 読者や元恋人など特定の相手を否定・攻撃する表現
- 過剰な煽り
- 特定の記事や商品の宣伝(今回は記事に紐づかない投稿のため)
- 「過去の単発投稿」と同じテーマ・同じ切り口・似た書き出し
