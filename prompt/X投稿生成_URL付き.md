# 投稿生成ルール

## 1. 基本姿勢

記事の宣伝広告ではなく、この記事を読んで考えたことをXで自然に共有する投稿を書いてください。

このアカウントは今、記事へのクリックよりも、投稿単体のインプレッション・エンゲージメントを
優先しています。1件目(hook)は、2件目や記事を読まない人にとっても、それ単体で
「分かる」「刺さった」「手元に残したい」と思える投稿にしてください。

## 2. 1件目(hook)の書き方

- 最初の1文を最も重要な部分として扱ってください。記事の見出しをそのまま繰り返すのではなく、
  記事の中の具体的な一場面や、読者がハッとする一文を冒頭に置いてください。
  問いかけ(「〜ない?」「〜してたりしない?」)で書き出さないでください。
- 選んだ気づきについては、答え・自分の考えまで1件目の中で言い切ってください。
  「その理由は、」「それって多分——」のように文の途中で切ったり、答えを2件目に伏せたりしないでください。
- 記事全体の要約や見出しの羅列にはせず、気づきは一つに絞ってください。

## 3. 2件目(payoff)の書き方

- 1件目を読んで興味を持った人に向けて、記事に書かれている具体的な方法・理由を一つ足してください
  (1件目の言い換えや繰り返しにしない)。
- 記事の他の部分にも同じくらい役立つ話がある、と自然に伝わる程度に留め、記事全体の要約はしないでください。
- 「自分を責めなくていい」「もう大丈夫」のような定型の励ましで締めないでください。
- 記事URLは投稿時に自動で追加されるため、本文にURLやリンクへの言及("下のリンクから"等)を
  含めないでください。

## 4. 禁止事項

- 「絶対に」「100%」など根拠のない断定
- 読者や元恋人など特定の相手を否定・攻撃する表現
- 過剰な煽り(「これを読めば解決」など)
- 「この記事からの過去の投稿」「直近のアカウント全体の投稿の書き出し」と同じ切り口・同じネタ・似た書き出し
- アカウント情報の「型の固定化」に挙げた書き出し・締め・切り方
- 「直近のトレンドワード」を無理やり詰め込むこと(自然に絡められそうな場合だけ触れてください)
