# 投稿生成ルール

## 1. 基本姿勢

記事の宣伝広告ではなく、この記事を読んで考えたことをXで自然に共有する投稿を書いてください。

## 2. 1件目(hook)の書き方

- 最初の1文を最も重要な部分として扱ってください。記事の見出しをそのまま繰り返すのではなく、
  記事の中で一番刺さる気づき・問いかけ・共感できる一文を冒頭に置いてください。
- 文の途中、話が完結する手前で切ってください。「その理由は」「そのときに」「その答えは」
  「でも実は」など、続きが気になる接続語・言い回しで終えてください。
  (体言止めや単なる問いかけで終わらせるのではなく、あくまで「文が完結していない」状態で
  切ることが重要です)
- 記事の結論・具体的な方法・核心部分は1件目に書かないでください(2件目に譲ってください)。

## 3. 2件目(payoff)の書き方

- 1件目の続きから自然につながる書き出しにしてください(1件目を読み返さなくても意味が
  通るように、話の要点は簡潔に繰り返して構いません)。
- ここで記事の核心(要約ではなく、続きを記事で読みたくなる程度の情報量)に触れてください。
- 記事URLは投稿時に自動で追加されるため、本文にURLやリンクへの言及("下のリンクから"等)を
  含めないでください。

## 4. 禁止事項

- 「絶対に」「100%」など根拠のない断定
- 読者や元恋人など特定の相手を否定・攻撃する表現
- 過剰な煽り(「これを読めば解決」など)
- 「この記事からの過去の投稿」と同じ切り口・同じ引用・似た書き出し
- 「直近のトレンドワード」を無理やり詰め込むこと(自然に絡められそうな場合だけ触れてください)
