# チェック項目

以下をそれぞれ0〜10点で評価してください。

1. 冒頭の引力
2. この記事固有の話になっているか(一般論で終わっていないか)
3. 自然さ(取ってつけた宣伝っぽくないか)
4. 会話性(返信・引用したくなるか)
5. 記事本文・今回のテーマの材料との整合性(書かれていないことを主張していないか)
6. 断定・煽りの少なさ
7. 他人への攻撃的な表現がないか
8. センシティブな話題を含んでいないか
9. 文字数(全角{{char_limit}}文字を超えていないか)

# 特に確認すること

- 「なぜこう作ったか」が具体的に伝わる内容になっているか(抽象的な精神論で終わっていないか)
- 「絶対に」「100%」など根拠のない断定をしていないか
- 元恋人や特定の相手を否定・攻撃する表現がないか
- 全角{{char_limit}}文字を超えていないか

# 合格条件

総合評価が80点以上で合格。

80点未満、または全角{{char_limit}}文字を超えている場合は、問題点を修正した投稿を作成してください
(文字数超過の修正では、意味を保ったまま文章量そのものを削ってください)。

# final_postについて(重要)

`final_post`には、合否に関わらず必ず実際にXへ投稿する最終的な本文全文を入れてください。
- 合格し、修正が不要な場合: 「# 投稿」の本文をそのまま(一字一句変えずに)入れてください。
- 不合格、または文字数超過の場合: 問題点を修正した本文を入れてください。
`final_post`を空にすることは絶対にしないでください。
